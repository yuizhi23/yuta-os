☁️ YuTa OS — Real-Time Live Sync (Yuki ↔ Nata)
⚡
🟢 Terhubung & Live (Real-Time)

Kamar "yuta-space-2026" aktif otomatis. Sinkronisasi real-time Yuki ↔ Nata selalu terhubung.

💡 Masukkan nama kamar yang sama persis di HP/Laptop Yuki & Nata.
🔥 URL Realtime Database resmi YuTa OS (Gratis & Real-Time Sync).
📖 Cara Bikin Database Firebase Gratis 1 Menit (Klik di sini)
  1. Buka console.firebase.google.com & login Google.
  2. Klik Add Project (Beri nama misal: yuta-os) lalu klik Create.
  3. Pilih menu Build → Realtime Database → Create Database (Pilih Singapore/US, pilih Start in Test Mode).
  4. Salin link database (misal: https://yuta-os-default-rtdb.asia-southeast1.firebasedatabase.app) dan paste di kotak atas!

⚡ Tarik Otomatis dari Google Calendar (Yuki & Nata) Akun Google Calendar Yuki & Nata sudah terhubung! Klik tombol di bawah untuk langsung menyelaraskan jadwal ke web:
📖 Panduan Lengkap: Cara Sambungkan 2 Arah (Google Cal ↔ Web)
  1. Dari Web ke Google Cal: Klik "Download All (.ics)" di atas, lalu import di Google Calendar Settings.
  2. Dari Google Cal ke Web: Di Google Calendar, klik ⚙️ Settings → Export untuk dapat file .ics, lalu klik tombol hijau "📂 Upload File .ics" di atas. Semua tugas Google Calendar langsung muncul di web ini!
  3. Atau via Link Live Feed: Buka Google Calendar Settings → Pilih nama Kalender → Salin "Alamat rahasia dalam format iCal" dan paste di kotak URL di atas.
